# 📝 Manual Testing Project – Evershop

This repository contains the complete documentation of a **Manual Software Testing Project** for the **Evershop Web Application**, conducted as part of the SQA: Manual & Automated Testing course from Ostad.

---

## 📁 Project Files Overview

| File Name                          | Description |
|-----------------------------------|-------------|
| `Q1 Requirement_.xlsx`            | Requirement analysis document (SRS) |
| `Q2 Testcase.xlsx`                | Designed test cases based on SRS |
| `Q3 Testcase Execution.xlsx`      | Test execution results with pass/fail status |
| `Q4 Defect Report_.docx`          | Documented bugs with details: severity, steps to reproduce, expected vs actual |
| `Q4 testcase and report.xlsx`     | Combined test cases and bug report |
| `Evershop API Collection.postman_collection.json`_
